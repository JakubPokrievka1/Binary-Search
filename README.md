Binary Search. This is code is my first implementation of a binary search. 
For the script to be used on Linux, it is the easiest ran via the terminal using "./binary_search.py", with the permissions "chmod +x binary_search.py" given to the file.
On Windows/MacOS, the script is the easiest ran through an IDE.
